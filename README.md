# 老後収支シミュレーター v0.9

老後収支を、月次計算・収入内訳・支出内訳・制度・実績・シナリオ・見直し条件まで同一計算エンジンで長期管理するPWAです。

## v0.9の主な変更
- 年間収支を「収入」と「支出」に分離。
- 固定費、光熱費、変動費、車、税・社会保険、保険、更新積立、旅行費を詳細表示。
- 各支出項目・旅行費・管理予算・追加収入を、開始年齢〜終了年齢の期間指定で一括更新。
- 詳細予定原価と管理予算を分離し、差額を予算バッファとして表示。
- 税・社会保険は計算可能な場合、2026年制度・自治体条件を将来へ仮適用した予定値を使用。計算不能時のみ月4万円を暫定使用。
- 確度区分に「区分の意味」と「現在設定値」を追加。
- 公的年金は個人設定JSONに65・70・75歳の公式見込を保持可能。

## 支出の考え方
詳細内訳は「予定原価」、年代別年間予算は「管理予算」です。

`管理予算 = 予定原価 + バッファ`

資産シミュレーションでは管理予算を支出正本として使い、詳細内訳を二重加算しません。予定原価が管理予算を超えた場合は負のバッファとして表示し、予算見直し対象にします。

## セキュリティ
- 個人の氏名・生年月日・資産額・年金額・iDeCo/DC額・退職金額・実績値は公開ソースコードへ埋め込まない。
- 個人設定は別JSONから読み込み、端末内へ保存する。
- 個人設定JSON、私的な要求仕様書、保留事項台帳、バックアップJSONは公開GitHubへコミットしない。

## 主な機能
- 月次の老後資産シミュレーション
- 収入・支出の項目別年間収支
- 期間一括入力
- 公的年金、NISA、iDeCo/DC、退職金、雇用保険、税・社会保険の制度ツール
- 資産推移、管理基準、予備枠
- 年次実績入力と再予測
- 最大3案のシナリオ比較
- 入力値の確度管理
- 95歳資産の増減要因分解
- 見直し条件の自動判定
- JSONバックアップ
- PWA対応
