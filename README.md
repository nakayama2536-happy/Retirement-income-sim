# ライフプランシミュレーター

収入、管理予算、資産、年金などの入力を使って資産推移を試算するアプリです。結果は概算です。

日常の操作、バックアップの範囲、復旧時の注意点は [利用案内](docs/USER_GUIDE.md) を参照してください。個人データやバックアップは公開リポジトリへ保存しないでください。

2026年10月10日時点の確認範囲：対象版 v0.9.7 / I-08 のクラウドChromeでは架空データの保存・一括復元・再読込み・2画面の書込み制御を確認しています。利用者のiPhoneではオフラインのホーム・比較画面表示を確認しています。全端末の動作を保証するものではありません。

2026年10月11日、隔離したChromiumと架空データで、通常キャッシュ更新、資材・更新プログラム取得失敗時の旧版保持、対応バックアップの別保存領域への復元を確認しました。公開元0e348f4から本候補への更新と、更新前バックアップを公開元の本体へ復元する組合せも確認しています。試験用のキャッシュ識別子を使用した結果であり、すべての過去版との互換性を保証するものではありません。

説明変更箇所は390px・1280px幅のChromiumで確認済みです。iPhoneの完全終了後の起動、本候補のiPhone実機表示、本番更新後の確認は未実施です。税・社会保険の制度検証は別工程です。
