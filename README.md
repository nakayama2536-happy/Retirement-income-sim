# ライフプランシミュレーター

収入、管理予算、資産、年金などの入力を使って資産推移を試算するアプリです。結果は概算です。

日常の操作、バックアップの範囲、復旧時の注意点は [利用案内](docs/USER_GUIDE.md) を参照してください。個人データやバックアップは公開リポジトリへ保存しないでください。

2026年10月10日時点の確認範囲：対象版 v0.9.7 / I-08 のクラウドChromeでは架空データの保存・一括復元・再読込み・2画面の書込み制御を確認しています。利用者のiPhoneではオフラインのホーム・比較画面表示を確認しています。全端末の動作を保証するものではありません。

通常更新、更新失敗時の旧版起動、旧本体と対応バックアップによる復旧の実ブラウザ試験は未完了です。iPhoneの完全終了後の再起動も確認待ちです。本修正候補の画面変更は実ブラウザ未確認・未公開です。税・社会保険の制度検証は別工程です。
