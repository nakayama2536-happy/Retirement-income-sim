# 老後収支シミュレーター v0.8 final

老後収支を、月次計算・実績・制度・シナリオ・見直し条件・年次点検まで同一計算エンジンで長期管理するPWA試作版です。

## セキュリティ
- 個人の氏名・生年月日・資産額・年金額・iDeCo/DC額・退職金額・実績値は公開ソースコードへ埋め込まない。
- 個人設定は別JSONから読み込み、端末内へ保存する。
- 公開テストは合成データだけを使用する。
- 個人設定JSON、私的な要求仕様書、保留事項台帳、バックアップJSONはGitHubへコミットしない。

## 主な機能
- 月次の老後資産シミュレーション
- 公的年金、NISA、iDeCo/DC、退職金、雇用保険、税・社会保険の制度ツール
- 資産推移、管理基準、予備枠
- 年次実績入力と再予測
- 最大3案のシナリオ比較
- 入力値の確度管理
- 95歳資産の増減要因分解
- 見直し条件の自動判定
- 年次点検
- JSONバックアップ
- PWA対応

## v0.8
