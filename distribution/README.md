## 死亡時期の比較とH-MORT-06修正候補

「結果を見る → 死亡時期の比較（未反映）」から、本人・配偶者のいずれか一人の死亡月、遺族年金を含む合計公的年金の仮年額、管理予算の費目別仮配分と倍率を指定して比較します。死亡翌月の収支と費目別月額、年齢期末の資産差を表示します。死亡月の元の年金を維持し、翌月から入力した合計額へ置換します。

採用条件・保存済み比較案・実績・バックアップ・クラウドを変更しません。死亡比較の保存・基準案への反映はなく、再起動で入力中の比較は失われます。受給権、繰下げ中の個別給付、税・社会保険再算定、相続、保険金、iDeCo死亡一時金、両者死亡後は未対応です。

操作方法は配布物にも含まれる[利用案内](docs/USER_GUIDE.md)を参照してください。[死亡比較の開発用仕様書](https://github.com/nakayama2536-happy/Retirement-income-sim/blob/review/hmort06-budget-pension-20261026/docs/MORTALITY_COMPARISON_20261026.md)とCI・テストはGitHub側の資料です。実行用配布物には仕様書やテストを含めません。PR #37の公開前後検証と、今回のH-MORT-06最終headの検証は別の証拠として扱います。最新の対象head・結果・制限はこの開発ブランチのDraft PRとActionsを参照してください。

### 今回の明確化

- 死亡後支出は「元の月次管理予算−費目別減額合計」。減額は同じ月の対象費目額×(1−倍率)で、年齢期支出・収支・資産へ一度だけ反映します。増額は負の減額として区別します。
- 食費などの配分0％では倍率を変えても減額0です。初期の未配分100％では支出変更がないことと、全体の実効割合を明示します。登録済み費用明細を自動取得したものではありません。
- 年金合計の手入力に遺族年金が自動追加されることはありません。資料確認済みの参考計算では自身の年金・遺族厚生の差額・合計を分けて表示し、手入力合計の内訳は未確認とします。
