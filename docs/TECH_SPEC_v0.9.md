# 老後収支シミュレーター 公開技術仕様 v0.9

基準日: 2026-09-25

## 年間収支
収入と支出を別管理する。収入は本人・配偶者の労働収入、公的年金、iDeCo/DC年金、雇用保険、臨時収入を分離する。資産運用益は資産増加要因として別表示する。

支出は固定費、光熱費、変動費、車、税・社会保険、保険、更新積立、旅行費へ分離する。各項目は年齢範囲ごとに金額を保持できる。

## 期間一括入力
開始年齢・終了年齢・金額・月額/年額を指定し、対象期間を一括更新する。既存期間と重なる場合は前後期間を自動分割して値を保持する。

## 予定原価と管理予算
詳細内訳から算出した支出を「予定原価」、年代別年間予算を「管理予算」とする。差額をバッファとして表示する。資産計算は管理予算を正本とし、詳細内訳は別加算しない。

## 税・社会保険予定額
可能な場合は本人・配偶者の給与・公的年金等から、所得税・住民税・国保/後期高齢者医療・介護保険の参考額を自動計算し、支出内訳の予定値とする。制度基準は2026年現行制度の参考であり、将来確定値ではない。計算不能時は設定された暫定額を使用する。

## 公的年金
個人設定JSONでは本人・配偶者を別管理し、65・70・75歳等の公式見込値を比較用に保持できる。基本ケースで採用する開始日・年額は別フィールドで管理する。

## 確度区分
確定、公式見込、会社見込、計画、仮定、シナリオ、未確認を区別し、区分説明と現在設定値を画面表示する。

## 個人情報
公開コードに個人値を含めない。個人設定JSONはGitHubへコミットしない。
