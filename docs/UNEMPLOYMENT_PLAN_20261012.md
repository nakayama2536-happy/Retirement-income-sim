# 失業給付の説明・受取予定（実装候補）

目的：退職後の給付を説明し、本人の受取予定を入力・確認・保存できるようにする。既存の採用値を自動変更しない。公開経路は既定のGitHub Pagesを維持する。

- unemployment.receiptPlan.version=1。未設定は旧動作を維持。none/basic/highAgeを明示選択する。
- 65歳の誕生日前日を境界に種類を検証。離職日は登録済み本業退職日との一致を要求し、計画外への逆算をしない。
- 給付日額は整数円、日数は整数。高年齢給付は30/50日分、1か月の一括受取。基本手当は1～14か月に日数を配分し、端数日は最終月へ。資格上の所定日数や期限の判定は未対応。
- 月初残高への運用後、従来の収入計上経路のunemploymentへ月次計上。旧baselineModeの給付を置換。給与生活のnet_transfer指定は尊重し非加算。臨時収入として重ねない。
- ホームのイベントはプランから導出し、config.eventsに複製保存しない。月内代表日であり実入金日ではない。
- 試算・反映・無効化・取消は既存detail workflowを使用。全期間を再計算し、実績・比較案を保持。未知の互換フィールドを保持。
- JSONに必要機能を付し、旧版の復元を停止。破損プランは保存前に停止。

制度の説明確認：2026-10-12。一次情報：ハローワーク https://www.hellowork.mhlw.go.jp/insurance/insurance_basicbenefit.html 、厚労省 https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/0000139508.html 。全体の制度適合性・本人資格を確認済みという意味ではない。

検証：架空データで新規13ケース（旧計上置換、月配分、入力不正、65歳境界、給与純入出金、重複、取消・陳腐化、互換復元、CSV、再予測）を追加。ブラウザE1は作成済み・未実測。詳細結果は更新記録と公開時PRへ残す。

本人確認待ち：離職日・理由、求職予定、雇用保険加入期間、日額の根拠となる賞与を除く賃金、受取予定月。本人条件の採用未実施。GitHub書込み・公開は今回の新差分について確認後。

戻し方：候補を不採用にする。公開後は今回コード差分のみ戻し、個人データを削除しない。新設定を含むJSONは旧版非対応のため、更新前の互換バックアップと旧本体の組を使用する。
