# 収支の詳細設定・結果確認の改善

基準：main cbebc668c321a06b9b08dd38d1f45635866e95cc（PR #9）。公開元manifestの41ファイルと開始時のローカル基準が一致。GitHub登録→CI・隔離ブラウザ検証→合格後のマージ・配信は利用者承認済み。各工程の実施結果はこの変更のPRに記録する。

## 目的と範囲
収入・支出を個別に設定し、年次表・月次/年齢期の全項目CSVで確認する。付随して比較案の手順、制度説明と個別試算の分離、一般設定の用語、階層ナビゲーション、目標補助線、ChatGPT確認依頼文出力を整える。

## 実装
- NISA・労働収入・公的年金・iDeCo・退職金、生活費・保険、臨時・追加収支へ入力を分離。税の既存参考計算は関連タブへ移動。
- 新入力は試算→確認→反映。全設定/比較案の変更で試算無効。保存失敗時保護。直前の詳細反映の取消は変更対象だけに限定し、対象が後で変わった場合は停止。
- 生活費・保険・税・旅行費の項目と年齢範囲を追加・変更。保存元を明示し、既存形式・未知情報を保全。内訳合計から年間予算を変更する操作は別に用意し、未確定や競合がある期間は停止。
- 退職金は税参考条件と資産受取を区別。計画開始前の受取を追加しない。既存受取行の明示連動、同月重複防止、連動中の別タブ編集を停止。
- 月次計算の観察値に本人/配偶者/夫婦合計労働、iDeCo一時金、連動退職金を追加。従来の年次集計数値・計算順序は不変。
- 全項目CSVは合計・内数・参考内訳・明細・設定を別列にする。未確定は空欄＋状態、文字列の式を無害化。内訳の管理IDで同名項目を区別。
- 年次表は大項目、収入中項目、支出中項目へ切替。目標は設定済み年齢末を補助線で結ぶ。設定値を増やさない。
- 保存済み現在設定・全比較案・実績・点検と全期間年次集計を含むChatGPT確認依頼文を生成。自動送信なし、下書き非対象、変更後は無効化。

## 維持条件・限界
計算周期、年齢期、月初運用益後の入出金、元の物価基準、管理予算正本、給与生活方式、本人の採用値を維持。NISAは内訳と利用枠で、口座別売却・税・将来残高は未対応。税制度の全体検証・本人受給条件・実機は別。CSVは設定対象資産の収支であり、純入出金方式の給与家計全体を再現するものではない。

制度入力範囲の確認（2026-10-11）：金融庁 https://www.fsa.go.jp/policy/nisa2/know/index.html 、iDeCo公式 https://www.ideco-koushiki.jp/guide/structure.html 。一時金/年金比率や受給資格は金融機関等で確認。
