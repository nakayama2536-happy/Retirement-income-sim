# 100歳末対応：検証用実装仕様（未公開）
基準：公開main e5d5dbb662c4727ef6dc009be373434dc4fc219e、tree 880db14f9f8feeed2db554115e5692497ad5990d。
ユーザー依頼：100歳末まで対応可能にする。本人の保存済み95歳計画を自動延長しない。

## 仕様
「データ・設定」内の「計算終了年齢を延長（100歳末まで）」から終了年齢と追加期間の予算を入力し、未反映試算→内容確認→明示反映の既存経路を使用する。
追加予算は元の物価基準価格。既存設定を明示選択でき、欠落・重複を拒否する。直接入力では追加年齢の予算だけを置き換え、元の期間と範囲外の未知情報を保持する。
本人・配偶者の就労終了、年金、iDeCo受取、NISA取崩し、臨時収支の終了は自動延長しない。予備枠全使用後の最終目安を延長後にも用いることを入力画面で明示確認する。
95歳末目標を100歳に移さない。100歳の参考目標は未登録なら未設定。元の年齢期の計算結果が変わる候補は停止する。
期間の単位・終了日は既存エンジンのendAgeの定義を維持。100歳期の終了時点まで（101歳期は含まない）。期間方式、月初運用→当月入出金、元の物価基準は維持。
保存案は変更しない。終了年齢の違う案の最終残高を同時点と表示しない。
取消は変更対象のみ。追加期間に実績・点検記録がある場合は停止。保存失敗・元設定や比較案変更時の停止は既存経路を使う。

## 完了境界
ローカルの実装・対象自動テスト用候補。本番公開・Firebase・本人採用値変更なし。版番号・配布manifestは公開準備前に再生成が必要。この候補を本番へ直接配置しない。


## 公開準備資材と確認の境界
バージョン識別子：`v0.9.7-age100-20261025`。画面・バックアップ・Service Worker・配布manifestを同版で固定。更新後の端末に自動適用するのはコードであり、計画終了年齢は更新前の採用値を保持する。対象自動テストと実ブラウザでの入力→未反映試算→明示反映→取消・再読込み、公開資材の一致をPR/CIで確認してから本番公開を別途判断する。
