## 画面の仕様

番号は識別用で、順番に全部押す必要はない。

|番号|操作|意味・条件|
|---|---|---|
|1|ログイン・ロック解除して開始|保持済み認証が有効ならメール・パスワード入力を省略し、合言葉で解除|
|2|今すぐクラウドに書き込む|端末からクラウドへ。手動操作は比較・必要なバックアップ確認後|
|3|クラウドの最新版を読み込む|クラウドから端末へ。未保存入力・双方変更を保護|

|5|自動保存を停止してログアウト|接続管理内。端末の保存データは消去しない|
|6|この端末のデータでクラウドを初期登録|未登録端末でクラウドが空の場合だけ|

現在の状態、番号付き手動操作結果、自動処理結果を分離する。手動操作の結果は自動処理で上書きしない。操作不可理由を表示する。照合後の入力・保存変更で確認を無効化する。クラウドを共通の確定データと呼ぶが、端末の未送信変更を無断で破棄しない。

## ログイン・安全条件

Firebaseの保持済み認証を既存SDKで再利用する。有効な登録マーカーと設定がある端末だけAuth確認を自動開始する。未登録・破損・停止済み端末は自動接続しない。Auth確認だけでは財務データを読み書きせず、明示的な暗号化解除後に既存の自動処理を開始する。

既存クラウドがあるときは合言葉による復号検証を完了してから自動書込みを許す。認証失効・別アカウントへの変更を検知したら停止する。暗号方式、更新世代の一致確認、未知の互換項目、置換前保全、復元後の確認待ち、初回の明示同意を維持する。

パスワードと合言葉はアプリに永続保存しない。新しい非秘密フラグ `lifeplan-private-sync-auto-resume-v1` は enabled/stoppedのみ。パスワード自動入力の属性は補助であり、本人iPhoneのFace ID・自動入力を確認済みとはしない。アプリ終了中・OS停止中・未解除・通信不可時の常時通信は保証しない。書込み結果が未確認なら保存成功と表示しない。

## 退職金の構想コメント

`config.retirement.conceptComment`。任意・複数行・2,000 UTF-16コード単位まで。計算には使わない。入力・試算では保存せず、全体シミュレーションへの明示反映で保存する。既存コメントがある場合、空欄を反映すると消去する。旧データに未設定なら空のメタデータを不要に追加しない。

HTMLのような文字列は文字として表示し、実行しない。現在のコメント変更で保存済み比較案を自動変更しない。設定・一括バックアップ・暗号化スナップショットに保持する。取消・保存失敗・試算前提の変化について既存保護を維持する。計算式、退職金額・日付、年次CSVの数値は変更しない。

## 検証手順と既存証拠

以前の変換専用workflow2本を直接検証workflowに置き換え、二重変換を防ぐ。過去の変換コード・実行記録・PRコメントは履歴として残す。通常CIと既存ブラウザ試験も、今回は反映済みルート本体を対象にする。

直接検証はコミット・tree・ソース一式を保全し、配布manifestの固定SHAと全資材を照合してから対象Node試験と実ブラウザ試験を行う。ワークフローは contents:read、資格情報の永続化なし、デプロイ工程なし。入力は架空データ、クラウドはループバック上の模擬データのみ。

初期候補59件、第2工程49件・ブラウザ9ケース、第3工程119件、第4A工程89件・ブラウザ18ケースはそれぞれの対象版・試験集合の結果。単純加算して独立テスト総数や全体保証を主張しない。制度適合性と本人の全採用条件監査は別工程。

## 公開前・復旧

公開前に新headの必要CI合格、個人情報・秘密の無混入、配布物一致、影響範囲、対応する更新前バックアップと版の組、本人の公開承認を確認する。通常利用画面からの確認だけを目的に、個人データの削除・初回再登録・復元は行わない。

問題時はコード差分とService Worker識別子を対応させて、承認された既定GitHub Pages経路で修正・復旧する。サイトデータ削除、クラウド再初期化、個人JSON自動復元は行わない。旧版本体に戻しても更新後に入力したデータまで復旧するとは保証しない。公開後のPC/iPhone通常操作とパスワード入力補助は本人環境で確認するまで別の確認待ちとする。
