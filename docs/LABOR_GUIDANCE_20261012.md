# アルバイト期間の参考表示・操作名の明確化

開始月は保存済みの退職月と失業給付受取終了月の遅い方の翌月。専用給付プランが未設定・不正なら未確定。給付なしと明示設定した場合は退職翌月。終了月は保存済み生年月日から76歳の誕生月を表示し、月を含まない既存終了日入力には翌月1日を案内する。参考表示のみで採用値は変更しない。

詳細設定の試算結果を入力直下に表示し、見出しへフォーカス・スクロールする。試算は未保存、反映は保存と全期間再計算、入力取消は未反映入力の破棄。年金・給与生活・内訳・追加収入・期間方式のボタンも役割に合わせて表記を統一する。内訳だけの反映は従来どおり管理予算を変更しない。

Nodeの境界3件と全体回帰710件成功。ブラウザE1に表示・入力取消・試算前後の保存不変の確認を追加したが実行未実施。公開承認後にCI/ブラウザ検証を行い、版識別・キャッシュ・配布manifestを更新する。既存の計算式と個人条件は変更しない。戻す際はコード差分だけを戻す。
