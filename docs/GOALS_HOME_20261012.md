# 年齢別目標の編集とホーム表示

目標を年齢期末の名目額（万円）で編集し、予測・差額を確認して反映する。0円と未設定を区別する。目標だけの変更では資産予測を変更しない。反映・取消・古い試算の停止は既存の保存経路を使用する。

ホームの予測・目標・差額・達成状況を一つのカードに統合し、凡例をオレンジ破線へ修正する。現行方式で未対応の最終年齢資産の要因分解は比較タブの補足へ移動する。

検証：Nodeの既存回帰と目標編集6件。隔離ブラウザW1で390/1280px、凡例の色・破線、反映・取消・再読込み後の保存を検証する。本人端末は別確認。新目標額の自動採用は行わない。
