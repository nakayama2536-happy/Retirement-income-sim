# H-MORT-07　死亡比較・制度参考額・費目別倍率（開発候補）

更新：2026-10-27。状態：Draft PR #39、未マージ・未公開。本人の金融原本は含まない。

## 今回のねらい
「先に死亡する人・死亡月・生存者の収入・管理予算の変化」で期末資産を比較する。死亡翌月から収入と通常支出を切り替え、死亡月は従来の年金・支出と一時費用のみを計上する。月初運用益→当月入出金の順序、年齢期集計、価格基準は既存通り。

## 年金シートの内訳
旧形式の `annualAtStart` を唯一の通常資産計算用年金年額として残す。任意の `breakdownAtStart` に `basicAnnual`, `employeeAnnual`, `otherAnnual`, `source` を追加。基礎・厚生・その他がすべて数字の場合だけ合計と従来年額の一致（許容差0.01万円）を確認する。内訳の未入力を0に補完しない。さらに任意の `survivorReference.earningsBeforeDeferralAnnual` と出典を記録し、年金総額や繰下げ増額後の厚生年金全額から報酬比例を推定しない。
これらは `pension-breakdown-reference-v1` 機能を要求する新しい保存形式であり、対応しない旧版への直接復元は拒否する。新内訳を反映しても本人・配偶者の年金合計と旧計算結果を変更しない。試算・確認・反映・直前取消・保存失敗保護は既存サービス経由で行う。

## 遺族厚生年金の条件付き参考式
日本年金機構の現行資料参照：https://www.nenkin.go.jp/service/jukyu/seido/izokunenkin/jukyu-yoken/20150424.html
65歳以上・生存者が自身の老齢年金を受給中・受給権、請求と繰下げ影響を確認した条件に限定する。
死亡者の繰下げ加算前報酬比例部分D、生存者の老齢厚生E、基礎Bに対して、
参考遺族厚生額 = max(0.75×D, 0.5×D+0.5×E)
遺族厚生差額 = max(参考遺族厚生額−E, 0)
生存者の年金合計 = B+E+遺族厚生差額。
生存者の受給前の期間や64歳以前、特殊給付・加算・遺族基礎・在職停止・税社保はこれで自動確定しない。旧計算に遺族年金を二重加算しない。登録値引用ボタンは受給権チェックを付けない。将来の制度変更・個別資格は別検証。

## 支出：費目ごとに独立倍率、残額も別倍率
`cashflow-sources.mjs` と `cashflow-reconciliation.mjs` の確定できる葉費目を利用し、親・子の重複加算を避ける。基準月額予算から確認済みの費目合計を差し引いた額を「未照合の管理予算残額」として、独立倍率0〜3を指定可能にする。内訳が不完全なら既知額のみ費目にし、未確定額を勝手に食費等へ按分しない。両出典が併存し採用元が不明なら出典の明示選択を求める。費目が予算超過、ID競合・年月不整合なら停止する。
計算例（架空、万円／月）：管理予算55、住居15×1.0、食費10×0.6、光熱5×0.8、未照合25×0.8 → 比較後45、減額10。インフレが適用済みの月次額に倍率を掛け、再度インフレを掛けない。
元の管理予算・参考内訳・税社保・利用者保存値を変更しない。亡くなる月は元の管理予算のまま、翌月から適用。給与生活・帰属不明の収入は既存の停止条件を保持。
