# 配置メモ v0.8

## GitHubへ置いてよいもの
`retirement-sim-v0.8` フォルダ内のファイルのみ。

## GitHubへ置かないもの
- 個人設定JSON
- 個人用要求仕様書
- 保留事項台帳
- 個人基準検証
- アプリから出力したバックアップJSON

## 更新時
1. 現在設定を一括バックアップする。
2. 公開用フォルダだけをGitHubへ反映する。
3. GitHub Pagesでv0.8が表示されることを確認する。
4. iPhone側で個人設定JSONを読み込む。
5. 「整合性チェック」でエラー0件を確認する。
6. 基準ケースを保存し直す前に、95歳末・管理基準・iDeCo/DC見込・年金開始月を確認する。

v0.2〜v0.7の端末内設定はv0.8へ移行可能だが、年次設定から月次設定へ変わるため、個人設定JSONの再読込を推奨する。
