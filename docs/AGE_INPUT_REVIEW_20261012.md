## 変更

- 詳細設定21か所の年月日・月入力、NISA利用枠の西暦年1か所、年金2か所、給与生活2か所に本人/配偶者の年齢補足。詳細欄は各入力の直下へ配置し、aria-describedbyで関連付ける。日付未入力・不正・生年月日未設定を年齢0として扱わない。

- iDeCo等、同じ設定を複数の欄で編集する際の古い入力を保護。元の入力データが更新され、欄が未編集なら再表示。編集中なら入力を保持し試算を停止。無関係の変更では下書きを破棄しない。試算候補は従来どおり全設定・比較案の変更で無効化。
