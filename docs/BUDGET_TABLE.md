# 年齢別年間予算の直接入力
予算設定の先頭に開始年齢・終了年齢・年予算（万円）の表を追加。行追加・削除、試算、明示反映、既存の保存失敗保護・限定取消を利用する。内訳形式は直接入力で不要。従来機能は補助欄へ折り畳む。
既存の年間予算上書き経路を使い、月次計算式・物価基準・65歳前の給与生活予算は変更しない。既存範囲外の設定・内訳・未知情報は保持。空欄・重複・期間空白・小数年齢・負額を拒否する。
検証: 架空データの自動49件成功（既存39件と追加10件）。年次支出、上書き再反映、物価、NISA連動、取消、古い試算拒否。構文・diff検査成功。本人データ変更なし。
