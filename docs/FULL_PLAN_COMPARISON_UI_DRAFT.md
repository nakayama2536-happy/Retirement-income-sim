# 全条件比較・未反映画面（Draft PR #27、未公開）

## 今回の範囲
公開済みStep 8の開始月・開始残高・物価基準・iDeCo年金初回月の未反映入力を使い、年間予算帯、本人アルバイト開始月、追加臨時収支をまとめて試算する。**入力・試算・CSV出力だけでは本人の採用値、比較案、バックアップを変更しない**。
開始資産の内訳確認と旧iDeCo含有フラグの明示置換は既存Step8の検証を使用する。未確定・空欄は0にしない。新規イベントは既存イベントに追加するため、二重計上を避ける。
年齢期CSVは既存annual-csv.mjsを使用する。月次計算結果と一致する年齢期末資産を照合できた場合だけCSVボタンを有効にする。未計算税や未確定制度は正確と主張しない。状態・保存の分離を保つ。

## 利用方法
データ・設定→全般設定の「計算開始月・開始残高・iDeCo受取月の比較試算」を開き、上側の接続条件を入力して確認→下側の予算帯・アルバイト開始月・追加臨時収支を入力→「全条件を比較（未反映）」。
結果と年次CSVを照合して確認する。比較用CSVは名前付きでダウンロードできるが、比較案の採用や端末保存はしない。現在設定が別画面で変わったときは試算を停止する。前の結果を残さない。
