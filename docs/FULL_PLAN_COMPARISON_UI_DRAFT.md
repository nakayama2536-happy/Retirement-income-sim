# 全条件比較・未反映画面（Draft PR #27、未公開）

## 今回の範囲
公開済みStep 8の開始月・開始残高・物価基準・iDeCo年金初回月の未反映入力を使い、年間予算帯、本人アルバイト開始月、追加臨時収支をまとめて試算する。**入力・試算・CSV出力だけでは本人の採用値、既存の比較案、バックアップを変更しない**。
開始資産の内訳確認と旧iDeCo含有フラグの明示置換は既存Step8の検証を使用する。未確定・空欄は0にしない。新規イベントは既存イベントに追加するため、二重計上を避ける。
年齢期CSVは既存 `annual-csv.mjs` を使用し、月次計算結果に一致する期末資産を照合できた場合に限り、未反映案のCSVを明示ダウンロードできる。税制度の適合性・未確定値を確定とは主張しない。

## 利用方法と保存の境界
データ・設定→全般設定の「計算開始月・開始残高・iDeCo受取月の比較試算」を開き、上側の接続条件を入力して確認→下側の予算帯・アルバイト開始月・追加臨時収支を入力→「全条件を比較（未反映）」。
比較案の入力・表示・CSVファイルのダウンロードまでは**ブラウザの採用済み条件・既存シナリオへの変更なし**。編集、別画面の条件変更、リセットは以前の比較結果を失効させる。
**比較CSVのファイル保存は、アプリのシナリオとして比較案を永続保存する機能ではない。** 現状の「シナリオ保存」は `app.mjs` の `saveCurrentScenario` により、採用済み `config` を保存するものであり、今回の候補 `proposal` の保存ではない。計画書の「表示・保存・CSV」のうち、比較案のアプリ内保存は未実装。採用・上書き・復元仕様を検討するまでは既存保存経路へ流用しない。
